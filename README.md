# Simple Appointment Booking

A standalone appointment-booking page for Erika Mickie.

## Features
- Package selection
- Date and time selection
- One appointment per day in browser storage
- Customer details
- 50% deposit calculation
- WiPay payment link
- Mobile responsive layout

## Important
This is a static front-end demo. Appointment data is stored in the visitor's browser localStorage and is not a shared production booking database. Payment verification should be connected server-side before treating an appointment as paid.

## Live deployment
The repository is prepared for GitHub Pages deployment.
